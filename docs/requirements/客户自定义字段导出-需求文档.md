## 1. 背景与目标

### 1.1 背景与问题

客户列表导出需要支持按业务需要选择字段，并按需导出关联表单和附件内容。字段顺序由系统默认规则决定；现有原型提供单栏字段多选、搜索和折叠交互。正式导出服务、权限细则及文件约束尚未由原型证明。

### 1.2 目标

在客户列表提供一致的导出入口和导出弹窗，使用户能够确定导出记录范围并选择导出内容和字段；字段按系统默认顺序输出。用户在提交前获得必要校验；任务完成后可获取导出文件，且导出数据遵循用户的数据和字段访问权限。

### 1.3 非目标

- 评论附件图片导出。
- 使用含表单关联显示字段的导出文件进行导入更新。
- 客户字段、关联关系、字段权限的配置管理。
- 导出任务历史、定时导出、分享链接和邮件发送。

## 2. 需求范围

| 范围 | 内容 | 说明 |
| --- | --- | --- |
| 本期包含 | 客户列表普通导出及导出已选客户入口；导出范围选择；表单字段单栏多选、搜索、全选和折叠；表格字段父子选择；按系统默认顺序导出；提交校验；任务处理结果和下载入口；弹窗交互与列表入口集成验收 | 目标行为以本文件功能说明为准 |

## 3. 功能说明

### 3.1 客户列表-导出数据弹窗

| 项目 | 说明 |
| --- | --- |
| 页面目标 | 选择默认或自定义导出方式，确认客户记录范围，发起导出并取得结果文件 |
| 页面入口 | 客户列表“导出”分段按钮；主按钮打开默认导出确认框，下拉菜单仅保留自定义导出 |
| 使用角色 | 具备客户列表访问权限且具有导出权限的用户；具体角色与授权方式待确认 |
| 原型依据 | 本地原型 `src/features/customers/components/CustomerWorkspace.tsx` 中客户列表和“导出数据”弹窗；该原型证明可见交互，不证明服务端能力 |
| 页面范围 | 默认导出确认、自定义导出范围配置、表单字段选择、任务状态、下载结果 |
| 页面输出/出口 | 取消或关闭返回客户列表；提交后展示任务状态；成功后下载文件；失败后展示原因并允许重新发起 |

#### 3.1.1 导出入口与打开说明

| 操作 | 展示/可用条件 | 系统处理 | 可观察结果 |
| --- | --- | --- | --- |
| 导出主按钮 | 当前筛选结果有可导出记录，且用户有导出权限 | 记录打开时的目标和数量；有选中记录时目标为已选客户，否则为当前筛选结果；打开默认导出确认框 | 确认框说明本次目标和记录数，并提供是否同时导出图片的选项 |
| 导出选项箭头 | 当前筛选结果有可导出记录，且用户有导出权限 | 下拉菜单仅展示“自定义导出...” | 选择后打开导出范围和字段配置弹窗 |

- 弹窗使用打开时确定的导出目标和记录集合；用户返回列表并修改选择或筛选条件后，不得静默改变已打开弹窗中的目标。是否需要关闭后重开以更新目标，由入口重新触发。
- 默认导出确认框保留图片导出选项；自定义导出弹窗按“导出范围”和“表单字段”组织，每次重新打开时恢复默认范围、全选可导出字段并清空搜索条件。
- 自定义导出弹窗顶部展示本次导出目标和客户数量，并显示“每 10,000 条数据将会生成一个 Excel 文档”。
- 首次打开及每次重新打开时，默认选择全部当前可导出字段、展开表单字段模块并清空搜索条件。
- 打开弹窗时，导出范围默认仅包含必选的“表单数据”。
- 没有可导出记录时不创建任务，提示“当前范围没有可导出的客户，请调整筛选条件或返回列表勾选客户。”

#### 3.1.2 导出范围说明

导出范围使用紧凑复选框，可同时选择多个范围；默认只展示选项名称，不常驻展示解释文案。仅当用户勾选“表单关联显示字段”或“关联表单”时，显示对应提示和后续配置。范围及规则如下：

| 范围 | 默认/是否必选 | 交互与输出规则 |
| --- | --- | --- |
| 表单数据 | 默认选中且必选 | 导出客户基础表单字段；不可取消 |
| 表单关联显示字段 | 默认不选 | 选中后显示说明：“选中表单关联显示，导出文档将无法用于导入更新” |
| 表单附件图片 | 默认不选 | 导出所选客户表单中的附件/图片内容 |
| 审批图片/附件 | 默认不选 | 导出审批流程相关图片和附件 |
| 关联表单 | 默认不选 | 选中后在该选项下方显示“关联表单类型”多选项，使范围选项与类型选择形成一个整体；选项应来自客户对象可用的关联表单配置 |

- 不提供“评论附件图片”选项。
- 选择“关联表单”后，至少选择一种关联表单类型才可提交；取消该范围时隐藏类型选择区。重新勾选时，取消该范围前已选类型可在本次弹窗会话内保留；重新打开弹窗后按默认状态初始化。
- 原型中的关联表单类型选项为“联系人”“回款”“项目”；正式环境应根据客户关联表单配置提供可选类型。
- 关联表单类型不可用或配置已删除时，提交前重新校验；提示用户更新选择，不创建任务。

#### 3.1.3 表单字段选择说明

表单字段模块采用单栏清单，按系统字段、基础信息、自定义字段和表格字段分组。用户直接勾选需要导出的字段；不展示单独的“已选字段”栏，不提供字段排序。

| 功能项 | 交互规则 | 校验/结果 |
| --- | --- | --- |
| 默认选择 | 每次新打开弹窗时默认勾选全部当前有权限且可导出的字段 | 字段清单显示默认选中状态；“数据 ID”始终必选 |
| 多选/取消 | 字段清单支持逐项勾选和取消 | 取消字段后立即从导出字段集合移除；数据 ID 禁止取消 |
| 搜索字段 | 按字段显示名称过滤字段清单 | 仅过滤可见候选项，不改变字段选择状态；清空搜索恢复完整清单 |
| 全部 | 支持全选和取消全部普通字段 | 操作作用于完整候选字段集，不受搜索条件限制；取消全部后仍保留数据 ID |
| 已选数量 | 模块标题行展示当前已选字段数 | 不单独列出已选字段清单 |
| 表格字段父子选择 | 表格字段支持展开/收起；勾选父级选择全部子字段，取消父级取消全部子字段 | 父级展示未选、部分选中、全部选中状态；父级本身不作为导出列，子字段按系统默认顺序输出 |
| 字段模块折叠 | 点击模块标题行的折叠控件收起或展开字段选择区 | 折叠仅隐藏内容，必须保留字段勾选状态；重新展开后状态不变 |

模块标题行展示已选数量。字段模块下方固定展示说明：“勾选需要导出的字段”。导出文件按系统默认字段顺序排列，不受用户勾选先后影响。

**字段定义与来源：**候选字段来自当前客户对象的系统字段、基础字段、自定义字段和可导出的表格子字段；系统字段示例包括“数据 ID、客户名称、跟进阶段、负责人、创建时间”。原型中的字段名称和数量仅为示例，正式清单以租户当前客户类型、字段配置、字段状态和用户字段权限为准。字段类型、值格式、敏感字段脱敏规则及不同客户类型合并导出的字段策略待确认。

#### 3.1.4 提交校验说明

用户点击“确认导出”时按以下顺序校验。前端校验用于即时反馈，任务服务必须再次校验，不能依赖前端作为权限边界。

| 校验项 | 通过条件 | 未通过处理 |
| --- | --- | --- |
| 导出对象 | 当前导出目标中至少有一条仍可访问且可导出的客户记录 | 阻止提交并提示调整筛选条件或选择记录 |
| 表单字段 | 至少包含一个有效字段，且包含必选字段“数据 ID” | 阻止提交并提示重新选择字段；服务端也需验证字段标识有效 |
| 关联表单类型 | 仅当“关联表单”范围被选中时生效；需至少选择一个当前有效类型 | 阻止提交并在关联表单类型区域提示补选或更新选择 |
| 用户权限 | 用户仍具备导出操作权限，且对本次记录、字段和附件有访问权限 | 拒绝任务创建；提示权限不足，不返回越权数据或附件 |
| 请求完整性 | 范围、字段 ID、顺序及关联表单类型格式有效 | 拒绝任务创建并提示重新提交；不得生成部分配置任务 |

- 重复点击“确认导出”不得创建重复任务；提交期间按钮应进入不可重复提交状态。
- 提交成功后进入处理中状态；提交失败时保留当前配置，展示可理解的失败原因，允许用户修正或重新发起。
- 若权限或数据状态在任务执行期间发生变化，任务按服务端实际授权结果处理，不得因客户端此前已通过校验而扩大可导出范围。被跳过的数据/字段是否导致整任务失败待确认。

#### 3.1.5 任务状态与结果说明

| 状态 | 进入条件 | 页面展示与操作 | 退出/恢复规则 |
| --- | --- | --- | --- |
| 编辑中 | 弹窗打开 | 展示范围和字段配置；提供取消、确认导出 | 取消关闭弹窗且不创建任务；重新打开按默认值初始化 |
| 处理中 | 服务端确认任务创建成功 | 展示处理中状态；可关闭弹窗 | 关闭仅影响弹窗展示。任务是否继续后台处理须由服务端能力确认；重新打开后是否可找回任务待确认 |
| 已完成 | 服务端确认文件生成成功 | 展示完成状态和下载操作 | 下载链接有效期内可下载；文件格式、有效期及过期反馈待确认 |
| 失败 | 服务端返回任务失败或无法生成文件 | 展示用户可理解的失败原因，并提供重新发起入口 | 重试按原配置重新提交前需再次校验权限和配置；重复提交由服务端保证不会错误复用旧结果 |

- 弹窗关闭、刷新页面或网络中断不得将“处理中”直接显示为“失败”；恢复后应根据任务服务返回的最终状态更新结果。任务查询/恢复能力及超时策略待确认。
- “下载”仅在任务已完成且用户仍有下载权限时可用。下载失败时保留任务结果并提示用户重试；文件已过期或无权下载时给出明确提示。
- 当前原型通过定时器模拟进度，并生成演示文本内容；该行为不代表已实现真实文件生成、异步任务、权限校验或可用 ZIP/Excel 文件。

#### 3.1.6 权限、数据保护与审计

| 权限层级 | 需求规则 |
| --- | --- |
| 页面/入口权限 | 是否可见和可触发导出入口由导出权限控制；隐藏按钮不能替代服务端鉴权 |
| 数据范围权限 | 普通导出和已选导出均须重新按当前用户数据范围过滤；不可导出无权访问的客户记录 |
| 字段权限 | 字段候选列表只展示当前用户可导出的字段；服务端按字段标识复核，拒绝客户端伪造的无权字段 |
| 附件权限 | 附件与审批材料须按当前用户对记录和附件的访问权限校验；无权附件不得包含在文件内 |
| 敏感数据 | 数据脱敏沿用现有权限和脱敏规则；当前规则未提供，具体字段及导出场景待确认 |
| 操作审计 | 应记录发起人、组织/租户、导出目标类型、记录范围/数量、选择的范围与字段、任务结果和时间；日志保留期限、可查看角色及敏感值记录规则待确认 |

**角色权限矩阵（需在评审阶段确认角色映射）：**

| 角色 | 查看客户列表 | 发起导出 | 导出本人/授权范围数据 | 导出敏感字段/附件 | 查看他人任务结果 |
| --- | --- | --- | --- | --- | --- |
| 普通业务用户 | 按现有客户列表权限 | 待确认是否默认授权 | 仅限现有数据权限范围 | 按现有字段/附件权限 | 待确认 |
| 管理员 | 按现有客户列表权限 | 待确认是否默认授权 | 按现有管理员数据范围 | 按现有字段/附件权限 | 待确认 |

#### 3.1.7 验收标准与测试范围

验收分两层执行：自定义导出弹窗交互，以及客户列表入口集成。

**第一层：自定义导出弹窗交互**

1. 点击导出主按钮打开原默认导出确认框；目标为打开时的已选客户或当前筛选结果，记录数显示正确。
2. 导出目标为打开时的已选客户或当前筛选结果，记录数显示正确。
3. 新开自定义弹窗时表单数据默认勾选；所有有权限且可导出的字段默认选中；数据 ID 为必选且不可取消。
4. 单栏字段清单可逐项多选和取消；取消字段后不再导出该字段；不展示已选字段侧栏或字段排序控件。
5. 搜索仅过滤当前可见字段；无论搜索词为何，“全部”均作用于完整字段集；清空搜索后完整候选项恢复且已选状态保留。
6. 用户以不同顺序勾选字段时，导出文件仍按系统默认字段顺序输出。
7. 表格父级全选、部分选择、全取消的状态与子字段勾选状态一致；父级不出现在导出列中，子字段按系统默认顺序输出。
8. 折叠再展开表单字段模块后，已选字段状态保持不变。
9. 导出范围选项和说明文案准确；不显示评论附件图片；选择表单关联显示字段时显示“选中表单关联显示，导出文档将无法用于导入更新”；审批范围名称为“审批图片/附件”。
10. 选择关联表单范围但未选择类型时，无法创建任务并出现明确提示；选择有效类型后可继续提交。
11. 导出记录为空、字段 ID 无效、权限不足时，提交被阻止且不产生任务；用户看到可理解的反馈。
12. 提交中重复点击只产生一个任务；服务端返回处理中、成功和失败时分别显示对应状态；成功状态提供下载，失败状态显示原因和重新发起入口。

**第二层：客户列表入口集成**

1. 无已选客户时主按钮与下拉菜单使用打开时的当前筛选结果；有已选客户时使用打开时的已选记录。
2. 主按钮打开默认导出确认框；下拉菜单仅提供“自定义导出...”并打开配置弹窗；两者显示的记录数量均与打开时快照一致。
3. 任务创建所使用的目标类型、记录范围、导出范围和字段集合与最终确认内容一致，文件字段顺序符合系统默认顺序。
4. 列表入口无权限、空筛选结果、已选记录在提交前变为不可访问等情况下，服务端拒绝越权导出并给出可判定结果。

**测试约束：**验证用户可观察行为及任务输出，不断言内部组件状态或变量名。沿用项目现有组件测试基础；接入服务端异步任务后，在任务服务/API 层补充权限拒绝、重复提交、失败恢复、下载失效和执行期间权限变化测试。具体测试框架随项目现状执行。

#### 3.1.8 待确认问题

| 编号 | 待确认内容 | 未确认影响 | 建议确认方 |

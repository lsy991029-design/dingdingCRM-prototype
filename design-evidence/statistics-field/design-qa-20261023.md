## 五项视觉检查

| 检查面 | 结论 |
| --- | --- |
| 字体与排版 | 使用现有系统字体和 14px 正文层级；标题、标签、说明、数值层级可辨；窄屏文字未覆盖控件 |
| 留白与布局 | 继承 6px 圆角、36px 控件及标准左右内边距；四个配置项按任务顺序排列；长内容在弹窗主体滚动，标题和操作区独立保留 |
| 色彩与令牌 | 复用 crmTheme，主色 #007FFF；白色容器、灰色背景、浅边框；未引入另一套品牌色或装饰背景 |
| 图像与图标 | 使用现有 crm-logo.png 和本地 AddIcon；其余操作使用项目已有 Ant Design 图标库，没有手绘 SVG 或伪造图片 |
| 文案与内容 | 使用企业后台文案；明确区分数据来源、统计方式、目标字段、统计范围；计数和日期极值均有解释；示例数据标识可见 |

## 交互验证

| 场景 | 实测结果 |
| --- | --- |
| 回款计数 | 3；目标字段固定为记录数且不可编辑 |
| 回款求和 | ¥ 70,000.00；目标只提供金额字段 |
| 回款金额最大、最小 | ¥ 35,000.00、¥ 15,000.00 |
| 回款时间最大、最小 | 2026-10-22 09:00、2026-10-08 10:30 |
| 日期极值切回求和 | 不兼容日期目标清空，结果回到待配置 |
| 仅已确认回款 | ¥ 55,000.00 |
| 修改首期金额 20,000 为 25,000 | 已确认合计自动变为 ¥ 60,000.00 |
| 将该记录从客户 A 关联至客户 B | A 自动变为 ¥ 35,000.00；B 自动变为 ¥ 73,000.00 |
| 缺少来源、重名、未填条件字段 | 均阻止保存并显示明确提示 |
| 来源改为合同 | 不兼容目标和旧条件清理，范围恢复全部关联数据 |
| 取消有改动配置 | 提供继续编辑／放弃修改选择 |
| 编辑已保存字段 | 标题为编辑，原有配置正确回显 |
| 无关联数据客户 | 数量、求和按 0 展示；时间类极值为空 |
| 窄屏 | 文档宽度 390；弹窗 x=8、宽374、底部操作在视口内；条件换行后可编辑 |
| 单文件独立加载 | 已在独立静态服务中打开；可配置跟进计数，保存后客户结果为3 |
